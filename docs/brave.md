# Brave Shortcuts

## Tab Management

| Action                      | Shortcut                  |
|-----------------------------|---------------------------|
| New tab                     | `Ctrl + T`                |
| Close current tab           | `Ctrl + W`                |
| Reopen last closed tab      | `Ctrl + Shift + T`        |
| Next tab                    | `Ctrl + Tab`              |
| Previous tab                | `Ctrl + Shift + Tab`      |
| Jump to specific tab        | `Ctrl + 1` → `Ctrl + 8`   |
| Jump to last tab            | `Ctrl + 9`                |
| New window                  | `Ctrl + N`                |
| New Private window          | `Ctrl + Shift + N`        |

## Navigation

| Action                      | Shortcut                  |
|-----------------------------|---------------------------|
| Go back                     | `Alt + Left Arrow`        |
| Go forward                  | `Alt + Right Arrow`       |
| Refresh                     | `F5`        |
| Hard refresh (ignore cache) | `Ctrl + Shift + R`        |
| Focus address bar           | `F6` |
| Search from anywhere        | `Ctrl + K`                |

## Bookmarks

| Action                      | Shortcut                  |
|-----------------------------|---------------------------|
| Bookmark current page       | `Ctrl + D`                |
| Toggle Bookmarks Bar        | `Ctrl + Shift + B`        |
| Open Bookmarks Manager      | `Ctrl + Shift + O`        |

## Other

| Action                      | Shortcut                  |
|-----------------------------|---------------------------|
| History (new tab)           | `Ctrl + H`                |
| Downloads (new tab)         | `Ctrl + J`                |
| Find on page                | `Ctrl + F`                |
| Full screen                 | `F11`                     |
| Zoom in                     | `Ctrl + +`                |
| Zoom out                    | `Ctrl + -`                |
| Reset zoom                  | `Ctrl + 0`                |
| Developer Tools             | `F12` |
| Print                       | `Ctrl + P`                |

## Customization

**Settings → System → Shortcuts**  
Change any conflicting shortcut to something free
